# Инструкция: Пайплайн обработки Базы Знаний

Этот пайплайн отвечает за скачивание статей с портала, их очистку и загрузку в векторную базу данных (Qdrant) для работы ИИ-агента.
Все команды нужно выполнять из корневой папки проекта (`агентная система поддержки`).

## Шаг 1. Сбор сырых данных (Парсинг)
Скрипт обращается напрямую к GraphQL API и скачивает все статьи.
**Команда:**
```bash
python scripts/fetch_graphql.py
```
- **Откуда берет**: `https://zakupki.mos.ru/cms/api/graphql`
- **Куда сохраняет**: `dataset/kb_graphql.json`

## Шаг 2. Очистка и разметка (Препроцессинг)
Скрипт очищает HTML-теги и автоматически определяет категорию документа (техническая, юридическая и т.д.) и его тип.
**Команда:**
```bash
python scripts/clean_kb.py
```
- **Откуда берет**: `dataset/kb_graphql.json`
- **Куда сохраняет**: `dataset/kb_clean.json` (Готовый датасет для индексации)

## Шаг 3. Интеллектуальный чанкинг и Индексация (Qdrant)
Скрипт разбивает документы на логические куски (чанки) с учетом их типа, превращает текст в вектора (эмбеддинги) и сохраняет в Qdrant.
**Команда:**
```bash
python RLT_project/rag/index_knowledge_base.py
```
- **Откуда берет**: `dataset/kb_clean.json`
- **Куда сохраняет**: Напрямую в векторную базу **Qdrant** (коллекция `data_files`).

> [!TIP]
> **Тестовый режим:** Если вы хотите протестировать индексатор быстро и не ждать расчет всех эмбеддингов, запустите его с флагом `--test`.
> ```bash
> python RLT_project/rag/index_knowledge_base.py --test
> ```

---
**Итог:** После выполнения этих трех скриптов, ваша база знаний полностью загружена в Qdrant и ИИ-агент (LLM) сможет использовать ее для ответов на вопросы пользователей.
