TITLE: Просмотр и редактирование Условий поставки
TAGS: Инструкция
============================================================

При нажатии на кнопку «Условия поставки» в столбце «Операции» открывается форма «Условия поставки для <Название позиции>». В этой форме у поставщика есть возможность добавлять и удалять регионы поставки для данной позиции.

Для каждого региона поставщик может установить минимальную партию, цену и количество для данной позиции. В одной строке поставщик может выбрать несколько регионов и проставить условия поставки для них.

Также для каждого набора регионов поставщик может устанавливать дополнительные условия: количество (от и до), Скидка (%), Цена с НДС и без НДС.
