1. Авторизация, вход и выход из сервиса ЭДО  
«Росэлторг. 
Электронный 
документооборот» 
— 
система 
электронного 
документооборота с роумингом и интеграцией с торговыми секциями ЕЭТП. 
Вход в сервис «Росэлторг. Электронный документооборот» синхронизируется с 
Росэлторг.ID и возможен только после регистрации и авторизации Пользователя в 
Росэлторг.ID с созданием компании и добавлением ЭП. Подробная инструкция 
изложена в документе «Руководство пользователя Росэлторг.ID», расположенном в 
сети «Интернет» по адресу: https://www.roseltorg.ru/knowledge_db/docs/documents. 
Чтобы получить доступ к сервису «Росэлторг. Электронный документооборот»: 
1. В Росэлторг.ID выберите пункт меню «Сервисы». 
2. Нажмите кнопку «Получить доступ» в блоке ЭДО «Росинвойс 2.0», в 
открывшемся окне выберите роль и нажмите кнопку «Заполнить заявку». 
3. Заполните все шаги заявки в форме получения доступа к сервису 
«Росэлторг. 
Электронный 
документооборот». 
Активируйте 
чек-бокс 
«Ознакомлен с Заявлением на получение доступа» после ознакомления с 
заявлением. 
4. Нажмите кнопку «Подписать и направить» (Рис. 1). 
После получения доступа к «Росэлторг. Электронный документооборот» на 
указанную почту пользователя приходит письмо с уведомлением об успешном 
присоединении к автоматизированной системе электронного документооборота.

Примечание: данный функционал доступен только администратору организации. 
После получения доступа в сервис «Росэлторг. Электронный документооборот» 
только администратор организации может управлять правами доступа сотрудников. 
Доступы пользователей «Росэлторг. Электронный документооборот»: 
• 
Сотрудник с правом на просмотр — пользователь может просматривать и 
скачивать входящие и исходящие документы. Скрыты разделы: «Создать 
документ», «Черновики», «Добавление контрагентов», «API». Отсутствует 
возможность подписания входящих документов, удаления контрагентов, 
смены тарифного плана, редактирования профиля организации. 
• 
Сотрудник с правом на работу с документами — пользователь может 
просматривать, скачивать входящие и исходящие документы; создавать, 
редактировать, подписывать, отклонять, отправлять на доработку. 
Скрыты разделы: «Добавление контрагентов», «API». Отсутствует 
возможность 
удаления 
контрагентов, 
смены 
тарифного 
плана, 
редактирования профиля организации. 
• 
Администратор «ЭДО» - пользователю доступна вся функциональность 
сервиса.

6.4 
Подписание документов с помощью машиночитаемой 
доверенности 
С 01.09.2024 представители организации (за исключением руководителя) при 
подписании электронных документов должны использовать МЧД и сертификаты 
электронной подписи для физических лиц. 
При подписании документа руководителем, для подписи документа нужно 
выбрать только сертификат электронной подписи, с информацией об организации в 
нем. Остальным пользователям, после выбора сертификата физического лица,  
необходимо выбрать МЧД.  
В поле «Сертификат» выберите требуемый сертификат для подписания, а в 
поле «Доверенность» выберите соответствующую доверенность (рис. 53).

8.8 
Интеграция через API 
Интеграция с Росэлторг. Электронный документооборот через API позволяет: 
• 
авторизоваться 
сторонней 
внешней 
системе

• 
отправлять запрос на создание документа. 
Интеграции через API возможна на тарифном плане «Корпоративный +». 
Для создания API-ключа: 
1. Выберите пункт меню «Компания» — «API». 
2. Нажмите кнопку «Создать ключ». Сгенерируется ключ для создания 
документов через API (рис. 175). Для обновления ключа нажмите кнопку 
«Обновить ключ». 
 
Рис. 175 Создание API-ключа 
Для создания документа через API нажмите ссылку «Документация». Откроется 
страница с описанием запроса на создание УПД (рис. 176).
