## Как запустить парсер Базы Знаний

Скрипт загрузки статей напрямую обращается к REST API портала, выкачивая все разделы в один JSON файл с полными HTML-текстами и абсолютными ссылками на картинки.

1. Убедитесь, что установлены все зависимости:
   `ash
   pip install -r requirements.txt
   `

2. Запустите парсер:
   `ash
   python scripts/kb_rest_scraper.py
   `

3. После успешного завершения, в корне проекта появится файл kb_all_articles.json, содержащий 516 статей.
