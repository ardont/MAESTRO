# Интеллектуальный Ассистент Поддержки (RAG) для Портала Поставщиков (zakupki.mos.ru)

Проект представляет собой вопросно-ответную систему на базе архитектуры RAG (Retrieval-Augmented Generation). 
Основная цель - точные и полные ответы на вопросы пользователей на основе базы знаний Портала Поставщиков (zakupki.mos.ru).

## 📁 Структура проекта

1. **dataset/** — Основная папка с данными. **Только эти данные используются для обучения и RAG.**
   - 1_legislation/ — законы и нормативные акты.
   - 2_instructions/ — инструкции и официальные документы с Портала Поставщиков (zakupki_mos_ru_kb_articles и zakupki_mos_ru_official_docs).
   - images/ — все картинки и скриншоты, загруженные из Базы Знаний, которые нужны для корректного отображения инструкций пользователям.
   - kb_all_articles.json — полный дамп всех 516 статей Базы Знаний (содержит HTML-код и локальные ссылки на папку images/).
   - Сводные .txt файлы — объединенные текстовые документы для векторной базы.

2. **scripts/** — Скрипты для работы с данными.
   - kb_rest_scraper.py — основной скрипт для скачивания всех статей базы знаний Портала Поставщиков через скрытый REST API.
   - download_images_final.py — скрипт для выкачивания всех картинок из статей в папку dataset/images/ и замены абсолютных ссылок на локальные.
   - un_me.py — скрипт настройки окружения (скачивание моделей, индексация).

3. **docs/** — Документация по архитектуре проекта.
4. **sandbox/** — Скрытая папка (добавлена в .gitignore), в которой лежат все черновики, старые логи и логика реверс-инжиниринга API, которые мы использовали при исследовании портала. Эта папка не должна попадать в финальный коммит.

## 🚀 Быстрый старт (Windows)

1. Установите зависимости:
   `ash
   pip install -r requirements.txt
   `
2. Запустите скрипт настройки окружения (скачивание моделей, индексация):
   `ash
   python scripts/run_me.py
   `

## Как запустить сбор датасета с нуля

Скрипт загрузки статей напрямую обращается к REST API портала, выкачивая все разделы в один JSON файл с полными HTML-текстами. Второй скрипт загружает картинки.

1. Запустите парсер:
   `ash
   python scripts/kb_rest_scraper.py
   `
2. Скачайте картинки и привяжите их локально к JSON:
   `ash
   python scripts/download_images_final.py
   `
3. Итог: в папке dataset/ появятся обновленные kb_all_articles.json (516 статей) и папка images/.
