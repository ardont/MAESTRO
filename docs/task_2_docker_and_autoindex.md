### Задача 2: Идеальный развертываемый Docker-контейнер (One-click Deploy)
**Цель:** Обеспечить 100% работоспособность проекта при первой сборке из GitHub (git clone -> docker compose up -> работает).

**Подзадачи:**
1. Переписать и оптимизировать `docker-compose.yml` и `Dockerfile`.
2. Настроить автоматическое скачивание и загрузку необходимых моделей (Qwen2.5/embedding) при старте контейнера, если они отсутствуют.
3. Внедрить **Auto-indexing**: скрипт инициализации, который при первом запуске (если векторная база пуста) автоматически парсит документы из `dataset/`, создает коллекции в Qdrant и загружает в них эмбеддинги.
4. Прописать корректные зависимости (`requirements.txt`), зафиксировать версии библиотек для исключения конфликтов в будущем.
5. Проверить миграции Django: они должны выполняться автоматически до старта web-сервера.
6. Убедиться, что первый диалог пользователя с ботом после запуска проходит без ошибок и задержек (прогрев моделей).
