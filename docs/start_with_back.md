# Запуск сервиса с подключением к https://github.com/Gospoduu/AlphaRAG.hack
## 1) Создайте докер-сеть
```
docker network create rlt_hack_network
```
## 2) По очереди - поднимаите оба срвиса
##    Сначала сервис бекенд-а (в нем же поднимается кафка), потом этот сервис.
##    Для того что бы запустить оба сервиса вызовите
'''
docker-compose up
'''
