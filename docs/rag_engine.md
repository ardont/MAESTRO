# RAG Движок и Индексация

Движок RAG (Retrieval-Augmented Generation) отвечает за умный поиск информации и формирование ответов. Ядро находится в `RLT_project/rag/`.

## Индексатор (`indexer/`)
Задача индексатора — подготовить текст из `dataset/kb_clean.json` к быстрому векторному поиску.

1. **`document_loader.py`**: Загружает очищенный JSON и отдает в виде списка словарей.
2. **`chunker.py` (Умный чанкинг)**: 
   - LLM имеет ограниченное контекстное окно, поэтому длинные документы режутся на "чанки".
   - Если документ это закон (`doc_type == "legislation"`), чанкер делит его строго по границам статей (например, "Статья 93").
   - Если это инструкция (`doc_type == "instruction"`), чанкер делит по Markdown-заголовкам (`##`).
   - К каждому чанку прикрепляется "хлебная крошка" (название документа и раздела), чтобы модель понимала контекст вырванного куска текста.
3. **`embedder.py`**: Превращает текст чанка в вектор (1024 числа) с помощью легковесной локальной модели `ru-en-RoSBERTa`.
4. **`qdrant_indexer.py`**: Загружает вектора, тексты и метаданные (категория, тип) в векторную базу данных Qdrant. Запускается всё через `index_knowledge_base.py`.

## Поиск и Генерация (`main_rag.py` и `router.py`)
Когда пользователь пишет вопрос в чат, происходит следующее:

1. **Guardrails (`router.py`)**: Вопрос проверяется на ненормативную лексику.
2. **Нормализация (`normalize_query.py`)**: Синонимы и сленг (например, "ЭЦП") заменяются на официальные термины ("электронная цифровая подпись"), чтобы улучшить векторный поиск.
3. **Маршрутизация (`router.py`)**: Определяется, к какой линии поддержки относится вопрос (Общая, Техническая, Юридическая). Присваивается `category_filter`.
4. **Поиск (Qdrant)**: Векторизованный вопрос ищется в базе. Фильтр категории позволяет искать технический вопрос только по техническим статьям, игнорируя законы. Выбираются 3 лучших совпадения.
5. **Генерация (Ollama / LLM)**: Формируется системный prompt, включающий вопрос пользователя и найденный контекст из БД. Локальная LLM (например, Llama 3) формулирует окончательный, структурированный ответ со ссылкой на первоисточник.
