# Пайплайн Парсинга Базы Знаний

Этот документ описывает, как данные извлекаются с портала поставщиков и подготавливаются для индексации. Модули находятся в директории `scripts/`.

## 1. `fetch_graphql.py`
Скрипт предназначен для быстрого и надежного извлечения всех статей базы знаний напрямую из внутренней БД портала через GraphQL API.

**Как работает:**
- Формирует POST-запрос с GraphQL `query` на эндпоинт `/cms/api/graphql`.
- Запрашивает поля `contentItemId` (идентификатор), `displayText` (заголовок) и `content.html` (основной текст).
- Сохраняет "сырой" ответ сервера в файл `dataset/kb_graphql.json`.

**Преимущества:**
Отказ от классического веб-скрапинга (BeautifulSoup/Playwright) позволил обойти защиты от ботов (Cloudflare), ускорить скачивание с часов до 1 секунды и избежать сбора визуального мусора (меню, футеры).

## 2. `clean_kb.py`
Скрипт постобработки, который превращает сырой HTML в идеальный для LLM текстовый формат и обогащает данные метаданными.

**Как работает:**
1. Парсит HTML через `BeautifulSoup` и извлекает чистый текст, сохраняя переносы строк.
2. Пропускает пустые страницы.
3. Анализирует текст и заголовок статьи для **категоризации** (функция `determine_category`) и **определения типа документа** (функция `determine_doc_type`).
4. Формирует итоговый датасет `dataset/kb_clean.json`, который содержит готовые объекты: `text`, `title`, `url`, `doc_type`, `category`, `file_name`.

Эти метаданные критически важны для следующего этапа (RAG Engine), так как позволяют корректно нарезать текст на чанки и настроить гибридный поиск.
