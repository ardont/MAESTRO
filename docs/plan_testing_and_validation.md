# Этап 3: Глубокое тестирование и валидация ссылок

## Подзадачи:
1. **Автоматическое E2E тестирование ответов**:
   - Создать набор из 20-30 вопросов, типичных для службы поддержки `zakupki.mos.ru`.
   - Написать скрипт, который прогонит эти вопросы через RAG пайплайн (`qa_test_suite.py` или аналогичный).

2. **Парсинг и проверка ссылок на 404 (Критично!)**:
   - Из каждого сгенерированного ответа извлечь все ссылки.
   - Сделать HTTP GET запросы по этим ссылкам.
   - Если хотя бы одна ссылка возвращает статус `404 Not Found` или ведет не на `zakupki.mos.ru` — тест считается ПРОВАЛЕННЫМ.
   - В случае провала, агент должен автономно вернуться к коду, исправить логику формирования ссылок в базе данных или генерации, и перезапустить тест.

3. **Финальный аудит**:
   - Завершить работу только тогда, когда 100% ссылок из тестовой выборки будут рабочими.
   - Подготовить финальный отчет в логах о том, что система полностью переведена на `zakupki.mos.ru` и работает без сбоев.
