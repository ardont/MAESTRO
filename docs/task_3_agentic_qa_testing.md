### Задача 3: Агентное QA-тестирование и сбор метрик (Agentic QA)
**Цель:** Провести глубокое тестирование системы, симулируя реальных пользователей, чтобы гарантировать качество диалогов и отказоустойчивость.

**Подзадачи:**
1. Разработать/улучшить Python-скрипт (`qa_test_suite.py` / `agentic_tester.py`), который запускает LLM-агентов, выступающих в роли "пользователей".
2. Агенты должны вести осмысленные диалоги с системой: задавать сложные вопросы, уточнять ответы, проходить Workflow по шагам, провоцировать систему (писать токсичные запросы, просить оператора).
3. Во время тестов скрипт должен собирать метрики:
   - Время ответа (TTFT - Time To First Token, общая задержка).
   - Корректность ссылок и прикрепления Markdown картинок.
   - Точность найденных данных (RAG Precision/Recall).
   - Процент успешных эскалаций на оператора.
4. Прогнать этот тест в течение продолжительного времени (нагрузочное тестирование) и собрать агрегированный отчет по метрикам.
5. Автоматически исправить выявленные баги (если тесты упали).
