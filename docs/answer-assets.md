# Источники и иллюстрации в ответах

RAG сохраняет все уникальные ссылки из citations и изображения из images
в итоговом Markdown-ответе. Они проходят через END_GENERATION и сохраняются
в тексте сообщения AlphaRAG, поэтому доступны и при повторном открытии чата.
Источники — документы, включённые в контекст ответа; модель не определяет
точную привязку каждого утверждения к статье.

Внешние изображения используются по HTTP(S), локальные `media/...` и
`images/...` — через memory-api на порту 8989. Compose монтирует локальную
папку media; images доступны из dataset/images внутри образа. Файлы должны
физически присутствовать по соответствующему пути.

Для доступа с другого компьютера задайте RAG_PUBLIC_URL равным публичному
адресу memory-api (например https://rag.example.org); localhost подходит
только для локального запуска. Внешние HTTPS-страницы требуют HTTPS и для
картинок. После изменений пересоберите rag и memory-api:

    docker compose up -d --build rag memory-api

На сайте картинки открываются в увеличенном виде по клику. Несколько ссылок
поддерживаются и в основном Markdown-рендерере, и в резервном без CDN.
